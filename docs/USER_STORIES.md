# User Stories — SocialSentiment

1. **Проверка публикации.** Как аналитик, я вставляю URL Instagram-поста или Reel, чтобы проверить его формат и инициировать анализ.
2. **Анализ реальных комментариев.** Как аналитик, я вставляю доступные мне реальные комментарии (один на строку), чтобы получить классификацию positive / neutral / negative.
3. **Поиск негатива.** Как менеджер, я фильтрую негативные комментарии, чтобы быстро увидеть жалобы.
4. **Статистика.** Как менеджер, я вижу количества и распределение тональности, чтобы оценить реакцию аудитории.
5. **История.** Как пользователь, я открываю последние сохранённые анализы, чтобы повторно посмотреть результаты.

## Границы MVP
- Instagram — единственная поддерживаемая платформа.
- Без официального API автоматический сбор комментариев не гарантируется и **пока не реализован**.
- Источник `user_supplied` означает комментарии, предоставленные пользователем, а не собранные парсером.
- Словарный классификатор — базовая эвристика, не обученная AI-модель; возможны ошибки на сарказме, контексте и отрицаниях.
- Нет регистрации, авторизации и разграничения доступа. Использовать только локально с несекретными данными.
