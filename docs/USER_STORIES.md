# SocialSentiment — User Stories

1. **Анализ по ссылке:** как аналитик, я вставляю ссылку на Instagram-пост или Reel и выбираю автоматический сбор, чтобы получить тональность доступных комментариев.
2. **Ручной ввод:** как пользователь, я вставляю комментарии построчно, чтобы проанализировать тексты без парсинга.
3. **Обзор реакции:** как менеджер, я вижу общее число комментариев и распределение negative / neutral / positive, чтобы оценить реакцию аудитории.
4. **Поиск и фильтрация:** как аналитик, я фильтрую комментарии по тональности и ищу по тексту, чтобы находить конкретные реакции.
5. **История и повторный анализ:** как пользователь, я открываю сохранённые отчёты и повторно классифицирую их комментарии, не собирая их заново.

## Ограничения
- Автоматический сбор зависит от Scrapfly, доступности публикации и комментариев; полный охват не гарантирован.
- Поддерживается Instagram. Регистрация и разграничение доступа не реализованы.
- Классификация вероятностная; сарказм, контекст и неоднозначные фразы могут приводить к ошибкам.
- История доступна без авторизации; проект предназначен для локального демонстрационного запуска.
