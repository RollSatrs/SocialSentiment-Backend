## Демонстрация преподавателю
1. Показать User Stories, ER и API до кода.
2. Показать PR из feature-ветки и объяснить изменения.
3. Запустить тесты и Postman.
4. Запустить UI, анализ и сохранённую историю.
5. Честно назвать ограничения автоматического сбора и отсутствие авторизации.

**Важно:** чекбоксы обозначают наличие файлов/кода, а не успешный локальный прогон. Без запуска команд нельзя утверждать, что тесты проходят.
